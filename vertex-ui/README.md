# Vertex UI

A modern React Admin Dashboard and UI Component Library built with:

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- React Router
- TanStack Query
- Zustand
- React Hook Form
- Zod

## Features

-  Light/Dark/System themes
- Reusable UI Components
-  Responsive Layout
-  Fast Development with Vite
-  Type-safe with TypeScript
